**Roccat** was a manufacturer for gaming mice and keyboards. They function out of the box except for the configurable
RGB lighting. Linux was never officially supported by the vendor. However Roccat did support community attempts to
create drivers and utilities such as [Roccat Tools](http://roccat.sourceforge.net).

## Installing

The following commands can be used to identify the devices:

```{=mediawiki}
{{hc|$ lsusb|Bus 003 Device 009: ID 1e7d:2dd2 ROCCAT ROCCAT Kone Pure Ultra}}
```
To [allow regular users access to the device](Udev#Allowing_regular_users_to_use_devices "wikilink") add a rule.
